## Objective

Develop an end-to-end system focused on:

- **MLOps (40%)**: Data pipeline, versioning, CI/CD, deployment
- **Generative AI (30%)**: RAG, conversational chatbot, embeddings
- **Traditional ML (25%)**: Classification and clustering models
- **Frontend (5%)**: Dashboard and chat interface
